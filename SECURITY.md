# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's [private vulnerability reporting](https://github.com/alebgl77/open-fullscreenshot/security/advisories/new).

Include the affected version, reproduction steps, impact, and any suggested mitigation. Please do not disclose the vulnerability in a public issue before it has been reviewed.
